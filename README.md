# Neutron Dashboard

Windows desktop application for **Neutron** thermal camera modules: live video, image controls
(brightness, contrast, polarity, zoom, flip, rotation, gain), palettes, calibration, device settings and
firmware update.

This repository hosts the **installers and release notes** only. It does not contain source code.

## Download

Get the newest version from the
[latest release](https://github.com/Yukon-Advanced-Optics-Worldwide/neutron-dashboard-releases/releases/latest).
Download the installer, named `Neutron_Dashboard_Setup-v<version>.exe`.

> Ignore the **Source code (zip)** and **Source code (tar.gz)** links GitHub adds to every release. They are not
> part of the application and are not needed.

## Requirements

- 64-bit Windows 10 (version 1809 or later) or Windows 11
- A Neutron module connected over USB
- No administrator rights: the application installs for the current user only

## Install

Double-click the downloaded installer, then:

1. Choose the destination folder (a folder in your user profile is proposed).
2. Optionally tick **Create a desktop shortcut**.
3. Click through **Ready to Install**.
4. Leave **Launch Neutron Dashboard** ticked to start the application right away.

A **Neutron Dashboard** group is added to the Start Menu.

## Uninstall

Use **Uninstall Neutron Dashboard** in the Start Menu group, or **Apps & Features** in Windows Settings.
This removes the install folder, including log files and update settings.
